# BRUTAL OS v3

Aplicación web móvil para configurar, ejecutar y registrar entrenamientos en casa.

## Archivos

- `index.html`: estructura de la aplicación.
- `styles.css`: diseño responsive y temas BOY/GIRL.
- `app.js`: generador, reproductor, historial, favoritos y resumen compartible.

## Publicación

La aplicación es completamente estática y no necesita instalación ni proceso de compilación.

1. Sube estos cuatro archivos a la raíz de un repositorio de GitHub.
2. Publica el repositorio mediante GitHub Pages o cualquier alojamiento estático.
3. Mantén juntos `index.html`, `styles.css` y `app.js`.

Los entrenamientos, favoritos y perfiles se guardan localmente en el navegador de cada dispositivo.
